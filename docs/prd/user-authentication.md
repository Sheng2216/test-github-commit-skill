# 用户认证 PRD

## 1. 背景与目标

为文档平台提供统一的账号体系，支持邮箱密码登录与第三方 OAuth 接入，并保证令牌在传输与存储环节安全。

## 2. 范围

- 邮箱 + 密码注册 / 登录
- OAuth 2.0 接入（GitHub、Google）
- 访问令牌（Access Token）与刷新令牌（Refresh Token）

## 3. 功能需求

- FR-1：用户可使用邮箱密码注册，密码强度需满足最小长度 8 位且含大小写与数字。
- FR-2：登录失败连续 5 次后锁定账号 15 分钟。
- FR-3：Access Token 有效期 60 分钟，Refresh Token 有效期 30 天。
- FR-4：支持「记住我」将会话延长至 7 天。

## 4. 非功能需求

- NFR-1：登录 P95 时延低于 300ms。
- NFR-2：令牌存储使用 Argon2id 哈希。
